# 项目登记与权威归属

`projects/registry.json` 只登记项目和适配器；`adapters/` 只保存项目权威入口、机器入口、证据位置和禁止能力。项目原文不得复制到 Team OS。

`ownership/` 保存跨层归属判断，供上下文编译和后续去重审计使用。它不是迁移脚本，也不授权删除项目内容。每份归属表必须满足：

- 项目可在没有 Munder 和个人 Team OS 时独立、安全运行；
- 依赖方向始终是 Team OS 定位项目，项目不反向依赖个人绝对路径；
- 项目业务、机器、Gate、生产和正式设计留在项目；
- 只有跨两个以上不同项目稳定复用且语义一致的方法才上移；
- TOS3 上下文编译和 TOS4 冻结评测闭合前，不因“已经提炼”删除项目的安全底线或执行入口。

归属表中的 `retain`、`extracted` 和 `dedupeAfter` 分别表示“必须留守项目”“通用语义已在 Team OS 建立，但项目覆盖仍保留”和“满足明确 Gate 后才允许评估去重”。
