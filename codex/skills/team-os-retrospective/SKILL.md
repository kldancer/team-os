# Team OS 短复盘

只读取当前结果合同、最终变更、验证证据和必要事件，不搬运完整 Transcript。回答五个问题：

1. 预期结果与实际结果是否一致？
2. 哪个事实最早区分了正确与错误方向？
3. 哪项协作产生了最终采用的独有证据？
4. 哪个步骤只是重复、等待或上下文搬运？
5. 下一次只改变哪一项规则？

输出“保留 / 删除或简化 / 单一改进实验 / 证据引用”。只记录已知的首次判别事实耗时、返工、用户纠偏和交接次数，不为了填满指标猜数。

若项目提供机器任务关闭入口，并且当前结果已经真正终结，把短摘要与已知指标写回该任务；否则只在最终答复中披露，不另建评测数据库。一次异常不晋升为永久流程；只有重复摩擦或稳定收益且用户认可时，才更新对应项目权威或 Team OS。
