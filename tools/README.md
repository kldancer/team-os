# Codex 原生工具通道

个人 AI 客户端、MCP、浏览器与代码分析工具由 Team OS 和用户级运行环境维护，不再提交到具体项目。项目仓库只保存业务代码、机器计划、项目 Gate，以及使用某种工具时必须遵守的领域约束。

## 当前通道

| 通道 | 用途 | 项目中的边界 |
| --- | --- | --- |
| Codex 原生文件与终端工具 | 搜索、编辑、测试和构建 | 服从项目 `AGENTS.md`、写集合与授权 |
| Go 语义工具 | 符号、引用、诊断和 Go 测试辅助 | 结果不能替代项目测试与机器 Gate |
| 浏览器/Computer Use | 真实页面和本机应用验收 | 只在任务需要真实入口时启用 |
| Kubernetes/远端工具 | 生产事实与已授权操作 | 必须经过项目生产 preflight 和写授权 |
| 官方文档/网络检索 | 时效事实与外部依据 | 优先官方来源，不把网页内容当作操作授权 |

## 配置归属

- Codex 权限、sandbox、用户级 MCP 和个人绝对路径只存在于用户运行环境，不进入项目 Git。
- Codex 客户端负责 Session、工具调用、权限和运行控制；Team OS 只维护稳定的工具用途与边界，不保存可执行凭据。
- 项目需要特殊工具时，在项目机器合同中声明能力需求，不复制个人安装教程。
- Key、Token、Cookie、登录态、真实 Session ID 和本机私有路径不得写入本目录。

当前个人工作主链只面向 Codex GPT-5.6 系列。新增 Provider 是以后可选的独立证据通道，不得成为项目执行的隐式依赖。
