# Claude 执行与恢复

## 归属

项目构建、刷新、Runner 与 Gate 是唯一执行权威。Claude 只负责调用、观察和综合，不维护另一份 doing/done 状态机；会话里的任务列表只是当前轮的进度展示，不是可恢复事实。

## 长命令

Bash 前台调用上限 10 分钟。预计更长的构建、刷新、完整回归先说明命令、目标、预计时间、hard timeout、日志位置和止损点，再以后台方式运行；完成会通知 Owner，不用轮询或睡眠等待。日志写到项目 `.work`，不写通用位置。会话或应用退出不等于命令已停止或已完成：恢复时先查实际进程、日志与组件 status，不直接重放远端写。

## 跨会话恢复

换会话、模型或 worktree 后，从项目事实恢复而不是从对话记忆：读取 `.work/tasks/<task>/` 的范围、验收与恢复记录，核对当前分支、未提交改动和组件 status，再继续剩余验收。Claude 记忆不保存任务状态或项目约束；需要跨任务复用的约束进入项目约束文件或权威文档。

## 旧 Runner 任务

用户明确恢复使用 `juspctl` 的旧任务时，直接使用项目原生 `status/tail/resume` 与收据规则。Claude 适配没有计划绑定脚本，不生成伪造的绑定或 PASS。

完成时核对真实 diff、适用 Gate 和原入口；恢复所需事实、授权范围、剩余验收保留在项目 `.work`，不把整个 Transcript 复制进去。
